# Dashboard Templates

## Purpose

Reusable dashboard and report templates, along with design guidance for effective business reporting.

## Contents

- **Excel-Dashboards**: dashboards built in Microsoft Excel.
- **Power-BI-Dashboards**: dashboards built in Microsoft Power BI.
- **KPI-Reports**: structured KPI reporting templates.
- **Dashboard-Design-Principles**: guidance on layout, color, and chart selection.

## Documentation Standards

Each dashboard or report in this folder should include:

- **Intended Audience** – Who will use it and their level of expertise.
- **Business Purpose** – The decisions the dashboard supports.
- **KPIs** – Metrics displayed, with definitions and targets.
- **Data Requirements** – Sources, fields, refresh frequency, and quality checks.
- **Layout** – Visual hierarchy, chart choices, filters, and navigation.
- **Interpretation** – How to read the visuals and what actions they suggest.

## Contribution Notes

- Add one topic per file, using descriptive file names.
- State assumptions and data sources clearly.
- Include only work that has been completed and verified.
- Remove the `.gitkeep` file from a subfolder once real content is added.
