# Excel SUM Function — Reference Example

**Status:** Educational reference; independent learner exercise not recorded.

## What It Means
`SUM` adds numeric values in a specified range.

## Why It Matters
Used to total sales, expenses, quantities, and other numeric measures.

## When to Use It
When the desired output is the sum of numeric cells. Review hidden rows, text values, and filtered data; `SUBTOTAL` may be more appropriate for visible-row totals.

## Formula
`=SUM(B2:B4)`

## Hypothetical Example
| Cell | Value |
|---|---:|
| B2 | 100 |
| B3 | 150 |
| B4 | 250 |

Enter `=SUM(B2:B4)` in B5.

## Expected Result
**500** (100 + 150 + 250).

## Interpretation
The three example amounts total 500 units.

## Business Application
Summing individual order values for a reporting period, after confirming valid orders and consistent units.

## Common Mistakes and Limitations
Incorrect ranges, numeric values stored as text, duplicate transactions, and mismatched reporting periods.
