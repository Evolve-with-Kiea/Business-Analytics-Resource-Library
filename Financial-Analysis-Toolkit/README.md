# Financial Analysis Toolkit

## Purpose

A toolkit of financial analysis methods and accounting calculations for evaluating business performance.

## Contents

- **Financial-Ratios**: liquidity, leverage, efficiency, and profitability ratios.
- **Profitability-Analysis**: margin, break-even, and contribution analysis.
- **Revenue-and-Expense-Analysis**: trend, variance, and mix analysis.
- **Cash-Flow-Analysis**: operating, investing, and financing cash flow evaluation.
- **Accounting-Calculations**: depreciation, accruals, inventory valuation, and similar calculations.

## Documentation Standards

Each resource in this folder should include the following sections:

1. **What It Means** – A plain-language definition.
2. **Why It Matters** – The business value of the concept.
3. **When to Use It** – Situations where it applies (and where it does not).
4. **Formula or Calculation Method** – The exact formula, syntax, or procedure.
5. **Step-by-Step Example** – A worked example showing each stage of the calculation.
6. **Expected Result** – The output the example should produce.
7. **How to Interpret the Result** – What the number or output tells a decision-maker.
8. **Real-World Business Application** – A realistic scenario where the resource is used.
9. **Common Mistakes and Limitations** – Frequent errors, assumptions, and caveats.

## Contribution Notes

- Add one topic per file, using descriptive file names.
- State assumptions and data sources clearly.
- Include only work that has been completed and verified.
- Remove the `.gitkeep` file from a subfolder once real content is added.
