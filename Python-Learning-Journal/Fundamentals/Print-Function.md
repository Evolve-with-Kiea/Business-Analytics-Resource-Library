# Python print() — Learning Reference

**Status:** Educational example; not a verified independent journal exercise.

## Explanation
The built-in `print()` function writes a textual representation of values to standard output by default. It is useful for inspecting values and displaying messages.

## Syntax
```python
print(*objects, sep=' ', end='\n')
```

## Annotated Example
```python
# Display a message
print("Hello, Python!")

# Display a simple business calculation
revenue = 100
expenses = 60
print(revenue - expenses)
```

## Expected Output
```text
Hello, Python!
40
```

## Explanation of Output
The first call displays a string. The second evaluates a subtraction and displays the integer result.
