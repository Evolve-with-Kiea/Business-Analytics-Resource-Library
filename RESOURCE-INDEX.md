## Status definitions

- **Published documentation:** README or guidance available; not proof of completed practice.
- **Existing workbook:** File is present; content quality and testing require separate review.
- **Planned:** Proposed learning material not yet completed.
- **Verified exercise:** Run or calculated, checked against expected results, and documented.

See [Quality and Data Guidelines](QUALITY-AND-DATA-GUIDELINES.md) before publishing a completed resource.
