# SQL Practice

## Purpose

Notes and exercises for learning SQL, progressing from fundamentals to applied projects.

## Contents

- **SQL-Fundamentals**: database concepts and basic SELECT statements.
- **Filtering-and-Sorting**: WHERE, ORDER BY, LIMIT, and related clauses.
- **Joins**: INNER, LEFT, RIGHT, FULL, and self joins.
- **Aggregations**: GROUP BY, HAVING, and aggregate functions.
- **Practice-Projects**: multi-step projects applying SQL to business questions.

## Documentation Standards

Each programming or query exercise in this folder should include:

- **Explanation** – What the concept is and why it is useful.
- **Syntax** – The general form of the code or statement.
- **Examples** – Annotated, runnable examples.
- **Expected Outputs** – The exact output each example should produce.
- **Practice Problems** – Exercises for independent work, with solutions kept separate where possible.

## Contribution Notes

- Add one topic per file, using descriptive file names.
- State assumptions and data sources clearly.
- Include only work that has been completed and verified.
- Remove the `.gitkeep` file from a subfolder once real content is added.
